## 1. 선정 이유 및 한 줄 요약

꿈인 경찰과 연관되어 자연스럽게 디지털 포렌식 분야에 대한 관심을 막연하게 가지고 있었는데, 이 작업과 관련하여 AI를 적용할 수 있다길래 어떻게 AI가 수사를 쪼개서 진행하는지 흥미가 들어서 이 영상을 고르게 되었다.

이 발표는 며칠씩 걸리던 Windows 디스크 이미지 포렌식 분석을 MITRE ATT&CK 기반의 계층형 멀티 에이전트와 자체 검증 구조로 자동화해, 3시간 이내로 단축한 실전 구축기와 한계를 다룬다.

> **MITRE ATT&CK:** 해커들이 공격할 때 쓰는 전술과 기법을 체계적으로 분류해 둔 글로벌 표준 프레임워크


## 2. 핵심 아키텍처

이 시스템에서 인간 분석가는 대략 이 시간에 침해가 발생한 것 같다는 초기 컨텍스트를 프롬프트로 입력하는 것뿐이며, 그 이후는 4단계 계층 구조의 AI 에이전트들이 수사를 넘겨받는다.

### 1) MITRE ATT&CK 기반 4단계 위임 구조

| 계층 | 에이전트 역할 | 구체적인 동작 예시 |
| :--- | :--- | :--- |
| 1단계(총괄) | Single Host Analyst Agent | 인간이 준 시간대만 보고 어떤 전술부터 볼지 결정 및 결과 상관분석 |
| 2단계(전술) | Tactic Analyst Agent | Initial Access 전술을 맡아 어떤 기법을 팔지 결정 |
| 3단계(기법) | Technique Expert Agent | Phishing 기법을 맡아 구체적 증거 위치를 지정 |
| 4단계(추출) | Summarizer Agents | 실제 디스크 이미지에서 로그를 읽고 2단계 필터링으로 핵심 행만 추출 |

**계층을 나눈 이유:** 아래로 내려갈수록 컨텍스트의 구체성이 날카로워진다. 처음부터 LLM에게 수천 개의 아티팩트 경로를 다 뒤지라고 하면 길을 잃지만, `시간대 -> 초기 침투 -> 피싱 -> Outlook 로그` 순으로 범위를 좁혀주면 정확도가 크게 올라간다.

> **아티팩트(Artifact):** 시스템에 남은 사용자나 공격자의 모든 활동 흔적

### 2) 2단계 스마트 필터링

디스크 로그를 통째로 LLM에 넣으면 토큰 한도를 초과하기 때문에, 이를 막기 위해 요약 에이전트를 둘로 쪼갠다.

1. **Bulk Summarizer(1차 거르기):** 날짜 범위나 파일 확장자 같은 거친 조건으로 원시 데이터를 필터링한다. 필터링된 데이터의 앞부분 몇 줄을 들여다보고 데이터가 여전히 너무 많으면 조건을 다시 조인다.
2. **Precise Summarizer(정밀 판독):** 걸러진 데이터를 한 줄씩 추론하며 실제 침해와 관련된 항목만 뽑아 위로 올린다.

### 3) 전문 분석 에이전트

로그만 봐선 놓치는 파일 시스템 흔적이나 악성 실행 파일은 별도의 전문가 에이전트가 맡는다.

* **File Analysis Specialist:** 경로, 파일 카빙, MFT 엔트리 등을 통해 디스크에서 파일을 찾은 뒤 파일 유형을 판별하고, 엔트로피 분석이나 내용 추출을 자율적으로 결정한다.

> **용어 정리**
> * **파일 카빙(File Carving):** 파일이 삭제되어 주소 정보가 사라졌을 때, 디스크의 원시 데이터에서 파일의 시작과 끝 패턴을 찾아 복구하는 기법
> * **MFT 엔트리(Master File Table):** 윈도우에서 모든 파일의 이름, 크기, 생성·수정 시간, 저장 위치 등을 기록해 둔 파일 목차 데이터
> * **엔트로피 분석(Entropy Analysis):** 파일 내부 데이터의 무작위성을 측정해, 악성코드가 분석을 피하려고 암호화나 패킹을 했는지 판별하는 기법

* **Malware Analysis Specialist:** 의심스러운 실행 파일이 나오면 외부 악성코드 분석 도구를 호출해 정적, 동적 분석을 수행한다.


## 3. 인상적이었던 부분

멀티 에이전트 시스템은 에이전트끼리 대화가 길어질수록 정보가 왜곡되고, 각 에이전트가 사건을 제각각 다르게 이해하는 지식 파편화가 발생한다.

**이에 대한 해결책 두 가지**

1. **공용 지식 데이터베이스:** 모든 에이전트가 공유하는 중앙 데이터베이스를 두고, 저장되는 모든 정보에 어떤 에이전트가 올렸는지 태그를 달아 정보의 계보를 추적한다.
2. **Judge Agent:** 보고서 생성 에이전트가 초안을 쓰면, Judge Agent가 이를 검토한다. Judge Agent는 중간 계층을 거치지 않고 최하단 에이전트에게 직접 원시 데이터를 확인하게 시킨다. 중간 전달 과정에서 생기는 '전화기 게임'식 왜곡을 원천 차단하고, 근거가 빈약한 주장은 반려하고 재조사를 지시한다.

> **전화기 게임식 왜곡:** 여러 사람이 한 줄로 서서 첫 번째 사람의 말을 끝사람까지 귓속말로 전달하는 게임에서 한 명씩 거쳐갈 때마다 조금씩 빠지거나 와전되어, 맨 끝에는 원래 말과 완전히 달라지는 현상


## 4. 실전 테스트 결과 및 성능 평가

발표팀은 싱가포르 국가 단위 사이버 방어 훈련의 실제 침해 호스트 디스크 이미지로 파이프라인을 검증했다.

* **구동 방식:** 별도 파인튜닝 없이 순수 추론 시점 프롬프트 및 툴 호출만으로 동작
* **사용 모델:** 모든 에이전트에 Kimi K2 단일 모델 적용
* **소요 시간:** 단일 호스트 전체 분석 및 검증 보고서 생성까지 3시간 미만

**실제 탐지한 공격 체인**
1. **초기 침투:** 오타 도메인을 이용한 스피어 피싱 이메일 및 악성 첨부파일 식별
2. **실행:** `update.cpl` 드로퍼가 C2 실행 파일을 내려받아 실행한 흔적 추적
3. **지속성:** C2 실행 파일이 매시간 반복 실행되도록 설정된 점 확인
4. **영향:** 6,000개 이상의 파일이 랜섬웨어 확장자로 변경된 사실 도출

> **용어 정리**
> * **드로퍼(Dropper):** 실행되면 내부에 숨겨둔 진짜 악성코드를 시스템에 몰래 설치하는 운반책 역할의 악성 파일
> * **C2(Command & Control):** 공격자가 감염된 PC에 원격으로 명령을 내리고 정보를 빼가기 위해 통신하는 제어 서버 및 악성 파일

### 정량 평가 (F1 Score)

개별 에이전트는 20회, 전체 호스트 보고서는 10회 반복 실행해 정밀도와 재현율의 조화평균인 F1 스코어를 측정했다.

| 평가 대상 | F1 스코어 | 비고 |
| :--- | :--- | :--- |
| 대다수 개별 에이전트 | 90% 이상 | 안정적인 아티팩트 식별 성능 |
| 실행 전술 에이전트 | 약 65% | 해당 케이스 자체의 포렌식 흔적이 희박해 인간도 추론이 어려운 구간 |
| 최종 Single Host 보고서 | 75% | 핵심 근거를 댄 실행 에이전트보다 오히려 상승 - Judge Agent의 거르기 효과 입증 |

현재는 단일 Windows 디스크만 지원해 네트워크, 메모리 분석은 불가하며 너무 기술적이라 비기술직이 이해하기엔 어렵다는 점이 아쉽다.

## 5. 느낀점

이 발표를 보면서 초반에 계속 들었던 생각은 이렇게 AI가 포렌식 분석가를 대체하는 거 아닌가라는 거였다. 하지만 발표자가 말하는 내용을 계속 들으면서 대체하는 것이 아니라 그저 분석가의 업무 무게중심을 기존의 노가다가 아닌 판단으로 옮겨주는 도구라는 생각이 들었다.

수백만 줄의 이벤트 로그와 MFT 엔트리를 훑어 타임라인을 맞추는 작업은 기계가 훨씬 빠르고 지치지도 않지만, 반대로 근거가 희박한 상황에서의 추론과 기술적 파편들을 엮어서 사람에게 설명할 수 있는 사건의 맥락으로 재구성하는 일은 여전히 인간의 영역으로 남아 있다.

가장 인상 깊었던 부분은 Judge Agent의 설계 철학이다. AI의 말을 그대로 믿지 않고 원본 로그를 직접 대조해서 증거가 없으면 버리게 하는 이런 구조를 통해, 보안과 포렌식이 단순 자동화가 아니라 검증 가능한 신뢰를 통해 수행된다는 점을 보여준 것 같았기 때문이다.

약간의 의문점이 들었던 부분은 F1 스코어가 75%라는 점이다. 인공지능개론 수업을 수강했을 때 F1 스코어에 대해 배우면서 90% 이상의 높은 기준에 대해서 좋다고 판단된다고 알고 있었는데, 75% 수준을 실무에 적용했다 가정했을 때 믿을 만한 수치인지에 대해 의문이 들었다. 디지털 포렌식은 법적 증거로 쓰이거나 기업의 침해 범위를 확정 짓는 작업이기 때문에 하나의 증거만 놓쳐도 치명적이므로 단독 사용으론 힘들지만, 인간 분석가 기준 며칠이 걸려야 나오는 윤곽을 3시간 만에 75% 수준의 초안으로 뽑아준다는 점으론 충분히 의미가 있을 것 같고 증거가 희박했던 구간을 75%까지 올렸다는 점에서 발전 가능성 역시 있을 것 같다.
